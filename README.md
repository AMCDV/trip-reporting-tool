# trip-reporting-tool

## Dev Setup

1. Create a python virtual environment
    ```sh
    python3 -m venv .venv
    ```
2. Activate the new venv
    ```sh
    . .venv/bin/activate
    ```
3. Install requirements
    ```sh
    pip install requirements.txt
    ```
4. Run the app
    ```sh
    flask --app src run --debug
    ```
